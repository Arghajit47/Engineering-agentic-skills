# ADF template routing index

Generated by `templates/adf/build.sh`. Do not edit by hand.

Templates are **strict**: every JIRA description, comment, reply, and subtask
body is posted from one of these files, substituted — never hand-composed ADF
and never wiki markup, HTML, or raw Markdown. Each skill owns its own templates
under `<skill>/templates/adf/`; paths in a SKILL.md are relative to that skill.

Validate before posting:

```bash
python3 scripts/adf.py --validate <filled>.adf.json
```

## Comment template

Every posting skill also owns `<skill>/templates/adf/comment.adf.json` for any
other comment on a ticket. There is no "quick comment" exemption — a one-line
comment uses the template too.

Skills with a comment template: `architect`, `ba`, `developer-agent-ecosystem`, `eng-manager`, `perf-budget`, `pr-review-and-merge`, `qa`, `refactor-debt`, `release-engineer`, `security-review`, `sre-watch`, `tech-writer`, `test-strategy`.

## Editing

Sources are `templates/adf/_src/<skill>/<artifact>.adf.md`; the routing text in
this table comes from `templates/adf/_src/_routing.tsv`. Edit the source and run
`templates/adf/build.sh` — never edit the generated `.adf.json` or this file.

Full ADF node spec: `rules/ADF.md`.
